┌─────────────────────────────────────────────────────────────────────────────┐
│ GETTING STARTED                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

  1. Launch GUI:        python3 run.py  (or: python run.py)
  2. Navigate to:       ⚙️ C++ Deployment  (in left sidebar)
  3. Follow workflow:   3 easy steps (see below)


┌─────────────────────────────────────────────────────────────────────────────┐
│ THE 3-STEP WORKFLOW                                                         │
└─────────────────────────────────────────────────────────────────────────────┘

  ╔═══════════════════════════════════════════════════════════════════════════╗
  ║ STEP 1: CONVERT MODEL TO TENSORFLOW LITE                                 ║
  ╚═══════════════════════════════════════════════════════════════════════════╝
  
    📁 Select Keras Model (.h5)
       ↓
    ⚙️ Choose Model Type: [LSTM | Transformer]
       ↓
    🔄 Click "Convert to TFLite"
       ↓
    ✓ Output: cpp_models/[type]/[type]_model.tflite + metadata


  ╔═══════════════════════════════════════════════════════════════════════════╗
  ║ STEP 2: BUILD C++ APPLICATION                                            ║
  ╚═══════════════════════════════════════════════════════════════════════════╝
  
    🔨 Click "Build C++ Application"
       ↓
    ⚡ CMake configures build
       ↓
    🔧 Compiles with TensorFlow Lite
       ↓
    ✓ Output: cpp_inference/build/radar_tagger


  ╔═══════════════════════════════════════════════════════════════════════════╗
  ║ STEP 3: EVALUATE MODEL WITH C++                                          ║
  ╚═══════════════════════════════════════════════════════════════════════════╝
  
    🎛️ Configure Options:
       • Threads: 1-16 (default: 4)
       • Benchmark Mode: On/Off
       ↓
    🎯 Click "Run C++ Evaluation"
       ↓
    📊 View Results:
       • Predictions
       • Performance metrics
       • Inference time
       • Throughput

┌─────────────────────────────────────────────────────────────────────────────┐
│ QUICK TROUBLESHOOTING                                                       │
└─────────────────────────────────────────────────────────────────────────────┘

  Problem                          Solution
  ─────────────────────────────────────────────────────────────────────
  Conversion fails                 Install: pip install tensorflow
  Build fails (CMake)              Install: CMake 3.15+
  Build fails (compiler)           Install: GCC 7+ or MSVC 2019+
  Slow performance                 Increase thread count
  Timeout error                    Reduce model size or increase timeout


┌─────────────────────────────────────────────────────────────────────────────┐
│ COMMAND-LINE USAGE (ALTERNATIVE)                                            │
└─────────────────────────────────────────────────────────────────────────────┘

  After building through GUI, you can also use command-line:

  cd cpp_inference/build

  ./radar_tagger \
      --model ../../cpp_models/lstm/lstm_model.tflite \
      --metadata ../../cpp_models/lstm/model_metadata.json \
      --test-data ../../cpp_models/lstm/test_data.bin \
      --test-binary \
      --threads 4 \
      --benchmark
