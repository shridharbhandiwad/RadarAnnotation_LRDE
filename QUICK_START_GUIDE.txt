STEP 2: TRAIN YOUR MODEL (Python)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

XGBoost Example:
  from sklearn.multioutput import MultiOutputClassifier
  import xgboost as xgb
  import pickle
  
  model = MultiOutputClassifier(xgb.XGBClassifier(n_estimators=100))
  model.fit(X_train, y_train)  # y_train shape: [n_samples, 11]
  
  with open('xgb_model.pkl', 'wb') as f:
      pickle.dump(model, f)

Random Forest Example:
  from sklearn.ensemble import RandomForestClassifier
  from sklearn.multioutput import MultiOutputClassifier
  import pickle
  
  model = MultiOutputClassifier(RandomForestClassifier(n_estimators=100))
  model.fit(X_train, y_train)
  
  with open('rf_model.pkl', 'wb') as f:
      pickle.dump(model, f)

COMMON ISSUES & SOLUTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: "Failed to load ONNX model"
  → Check file path is correct
  → Verify .onnx file exists
  → Re-export from Python

Issue: "Input size mismatch"
  → Ensure model expects 18 features
  → Check metadata feature_columns
  → Verify normalization parameters

Issue: "Unexpected number of output tensors"
  → Model must output 11 predictions
  → Check multi-output wrapper in Python
  → Re-train with MultiOutputClassifier

Issue: Build fails with "ONNX Runtime not found"
  → Check internet connection (auto-download)
  → Or install manually:
    Ubuntu: sudo apt-get install libonnxruntime-dev
  → Use: cmake .. -DUSE_SYSTEM_ONNXRUNTIME=ON

PERFORMANCE TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Faster Training:
  - Reduce n_estimators (50-100 is usually enough)
  - Reduce max_depth (4-6 for XGBoost, 8-10 for RF)
  
Faster Inference:
  - Use --threads 8 for multi-core systems
  - Build with Release mode (not Debug)
  - Use smaller models (fewer trees)
  
Model Size:
  - XGBoost: Typically 1-10 MB
  - Random Forest: Typically 5-50 MB
  - Reduce n_estimators to shrink size
