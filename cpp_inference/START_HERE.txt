On your Windows machine, run these commands:

  1. git pull origin main
  
  2. cd cpp_inference && rmdir /s /q build && mkdir build
  
  3. cd build && cmake -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release ..
  
  4. cmake --build . --config Release

That's it! The build should now work.

╔══════════════════════════════════════════════════════════════════════╗
║                  WHY THIS HAPPENED                                   ║
╚══════════════════════════════════════════════════════════════════════╝

TensorFlow Lite's CMakeLists.txt sets compiler flags like:
  -Dmax(a,b)=((a)>(b)?(a):(b))

On Linux: Works fine (shell passes it to compiler)
On Windows: BREAKS (cmd.exe sees > as redirection operator)

The fix patches TensorFlow's build files to remove these flags before
they can cause problems.
