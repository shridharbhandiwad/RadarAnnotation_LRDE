================================================================================
PROBLEM ADDRESSED
================================================================================

Issue:
  CMake C compiler test fails on Windows with:
  "The filename, directory name, or volume label syntax is incorrect"

Root Cause:
  Flags -Dmax(a,b)=((a)>(b)?(a):(b)) contain < and > which Windows cmd.exe
  interprets as shell redirection operators, not compiler flags.

Previous Solution (v1.0):
  - Basic regex to remove from CMAKE_C_FLAGS
  - Missed some edge cases (string(APPEND ...), etc.)
  - Could still fail if flags set in different ways

Current Solution (v2.0):
  - Comprehensive removal from ALL possible locations
  - 15 different regex patterns covering all known cases
  - Line-by-line removal as fallback
  - Successfully tested patterns
