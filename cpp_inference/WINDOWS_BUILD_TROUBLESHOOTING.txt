================================================================================
                              COMMON MISTAKES
================================================================================

❌ MISTAKE: Not cleaning build directory before retry
   FIX: Always do: rmdir /s /q build

❌ MISTAKE: Using wrong generator (not "MinGW Makefiles")
   FIX: cmake -G "MinGW Makefiles" ..

❌ MISTAKE: Using 'make' instead of 'mingw32-make'
   FIX: Use mingw32-make (or make.exe from MinGW)

❌ MISTAKE: Old CMake version
   FIX: Upgrade to CMake 3.16 or higher

❌ MISTAKE: Multiple MinGW installations conflicting
   FIX: Use only one MinGW, ensure correct one is first in PATH

❌ MISTAKE: Running from wrong directory
   FIX: Should be in cpp_inference/build/

❌ MISTAKE: Missing internet connection
   FIX: Dependencies download during first cmake run

❌ MISTAKE: Antivirus blocking build
   FIX: Add exception for build directory

     cd cpp_inference
     rmdir /s /q build
     rmdir /s /q cmake-build-*
     del /q CMakeCache.txt 2>nul
     
  2. Restart computer (clears file locks)

     mkdir build
     cd build
     cmake -G "MinGW Makefiles" ..
     mingw32-make

     - Verify MinGW installation
     - Re-clone the entire project
     - Check Windows updates
     - Try different MinGW version
