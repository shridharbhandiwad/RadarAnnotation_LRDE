  QUICK BUILD INSTRUCTIONS FOR WINDOWS (MinGW)
================================================================================

The eight_bit_int_gemm error has been fixed with multiple fallback solutions.

--------------------------------------------------------------------------------
RECOMMENDED METHOD: Use the new build script
--------------------------------------------------------------------------------

1. Open Command Prompt or PowerShell
2. Navigate to the cpp_inference directory:
   cd /d "D:\Zoppler Projects\RadarAnnotation_LRDE\cpp_inference"

3. Run the new build script:
   build_mingw_fixed.bat

That's it! The script will:
  ✓ Clean the build directory
  ✓ Configure CMake
  ✓ Automatically patch gemmlowp if needed
  ✓ Build the executables

--------------------------------------------------------------------------------
ALTERNATIVE METHOD: If the script fails
--------------------------------------------------------------------------------

If build_mingw_fixed.bat doesn't work, try the manual approach:

1. Clean build:
   rmdir /s /q build
   mkdir build
   cd build

2. Configure (first time - will download dependencies):
   cmake .. -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release

3. Check if gemmlowp was downloaded:
   dir gemmlowp\CMakeLists.txt

4. If gemmlowp exists, patch it:
   - Open: build\gemmlowp\CMakeLists.txt
   - Find lines containing "eight_bit_int_gemm"
   - Comment them out with # at the start of the line
   - Save and close

5. Reconfigure:
   cmake .. -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release

6. Build:
   cmake --build . --config Release
