================================================================================
                         IF BUILD FAILS
================================================================================

1. Check CMake version (must be 3.16+):
   cmake --version

2. Check compiler:
   g++ --version   (MinGW)
   OR
   cl              (MSVC)

3. Read documentation:
   cpp_inference/WINDOWS_CMAKE_VERSION_FIX.md    (CMake issues)
   cpp_inference/WINDOWS_MINGW_BUILD_FIX.md      (Build errors)
   cpp_inference/WINDOWS_BUILD_INDEX.md          (All docs)

4. Try emergency fix:
   cd cpp_inference
   emergency_fix.bat

5. Clean rebuild:
   cd cpp_inference
   build_with_gemmlowp_fix.bat clean
